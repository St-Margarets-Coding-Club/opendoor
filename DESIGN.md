# Design at OpenDoor

In this manual, we will document the process of building every version of OpenDoor as part of our initiative to replicate this in different cities.
Furthermore, each version of OpenDoor will have it's very own GitHub release too.

Each version's contents will include
- Version Name
- Developers Notes
- Tech Stack
- Detailed Instructions

# v1

📝 Developer Notes
This is the first viable version of OpenDoor.

🚀 Features
- Aesthetic user interface
- Sourced from major animal shelters
- Simple and easy to use

⭐ Tech Stack
Web Technologies
- HTML
- CSS
- JavaScript
- Python
- Flask

Cloud Technologies
- MongoDB Atlas
- Cloudinary
- Vercel

🦮 Instructions
1. Please take a look at `database` directory first as it contains how do we handle database contents
2. Then we advise you to check out the `server` directory as it contains the frontend and backend elements
3. Finally, we would advise you to find a small team before contacting us to help replicate this in your own city

*This file only contains the design process of the product and does not help with conversion or collaboration. Please feel free to contact us for help once you finish building a v1 for your city.*
